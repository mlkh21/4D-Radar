# 跨主机预处理差异诊断计划

## 目标

沿实际预处理调用链分析 IR、LiDAR、target 和 observed mask 跨主机不一致的原因，区分代码已证明、输出统计支持和仍需样本/环境验证的结论。

## 阶段

- [x] 核对启动脚本、实际参数与 manifest 身份计算。
- [x] 核对 IR、LiDAR、target、observed mask 的生成链及潜在非确定性来源。
- [x] 将服务器逐模态差异分布与代码路径对应。
- [x] 给出最小只读验证步骤和训练影响结论。

## 约束

- 不修改或重新生成数据集。
- 不覆盖用户对 `preprocess.sh` 的现有修改。
- 不运行长时间预处理或训练。

## 错误记录

- 暂无。

## 结论

- manifest 绑定的是核心 Python 预处理脚本，不绑定启动脚本、解包脚本、原始 bag、Raw 逐帧内容或运行环境。
- 本机 `preprocess-v2.sh` 复用既有 Raw；服务器 `preprocess.sh` 在服务器环境中重新解包，因此两条流水线的上游输入来源并不等价。
- Patchwork++ 具有跨帧自适应状态，当前多进程 worker 长期复用实例且动态领取任务，已用同一原始帧复现输出随历史变化，是 LiDAR 及派生 target/mask 跨主机差异的确认原因。
- IR 每帧都经过 OpenCV 解码/PNG 重编码、灰度读取和 512x640 到 480x640 缩放；环境与 Raw 身份均未被 manifest 绑定，需服务器样本摘要进一步区分。
